# 💰 Banking Automation System

A web-based banking system built using Python, Flask, MongoDB, HTML, and CSS. It allows users to register, log in, deposit and withdraw money with proper session and database handling.

---

## 🚀 Features

- User Registration with name, account number, password, and balance
- Secure Login system with sessions
- Dashboard to:
  - View account details
  - Deposit money
  - Withdraw money
- Real-time database updates via MongoDB
- Simple and clean web UI using HTML/CSS

---

## 🛠️ Tech Stack

- **Backend:** Python (Flask)
- **Frontend:** HTML5, CSS3
- **Database:** MongoDB
- **Tools:** VS Code, MongoDB Compass
