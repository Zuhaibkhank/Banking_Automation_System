# 🏦 Banking Automation System

## 📌 Overview

This project is a **web-based banking system** built using Python and Flask.
It allows users to create accounts, deposit/withdraw money, and manage transactions.

---

## 🌐 Live Demo

[![Live Demo](https://img.shields.io/badge/Live%20Website-Click%20Here-green?style=for-the-badge)](https://banking-automation-system.onrender.com/)

## 🚀 Features

* 👤 User account creation
* 🔐 Login system
* 💰 Deposit money
* 💸 Withdraw money
* 📊 Balance check
* 🗄️ Data stored in MongoDB

---

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS
* **Backend:** Python (Flask)
* **Database:** MongoDB
* **Tools:** VS Code

## ⚙️ Installation & Setup

```bash id="banksetup"
# Clone repo
git clone https://github.com/zuhaibkhank/Banking_Automation_System.git

# Go to folder
cd Banking_Automation_System

# Install dependencies
pip install -r requirements.txt

# Run app
python app.py
```

---

## 📊 How It Works

1. User creates an account
2. Logs into system
3. Performs transactions (deposit/withdraw)
4. Data stored in database
